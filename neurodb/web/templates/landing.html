{% trans "Questions we hear often" %}

{% trans "Who can use NeuroDB?" %}

{% trans "UNICEF Lebanon staff with a registered account. Viewers see all dashboards and reports, section editors can also comment on their section’s indicators, and administrators manage configuration. Selected resources can be opened to the public by the NeuroDB team." %}

{% trans "How do I get access?" %}

{% if SUPPORT_EMAIL %}{% blocktrans %}Write to {{ SUPPORT_EMAIL }} with your section and the role you need. Once registered, sign in with your UNICEF Microsoft account — no extra password.{% endblocktrans %}{% else %}{% trans "Ask the NeuroDB administrators in the Planning, Monitoring and Evaluation section. Once registered, sign in with your UNICEF Microsoft account — no extra password." %}{% endif %}

{% trans "Where does the data come from?" %}

{% trans "Results come from partner reports in ActivityInfo; programme documents, donors and assurance from eTools; population estimates from the official planning figures loaded each year. NeuroDB never asks partners to report twice." %}

{% trans "How current is it?" %}

{% trans "Sources synchronise every night. The data health page shows when each source was last updated, and pages warn you when a database has not been imported recently." %}

{% trans "What does “on track” mean?" %}

{% trans "An indicator is on track when its achievement is within ten percentage points of the share of the year that has passed. Well above is “over target”, well below is “off track”, and indicators without a target are shown separately." %}

{% trans "Can I export the data?" %}

{% trans "Yes. Every table can be copied or downloaded as CSV, raw data is available in Excel, and dashboards have a printable snapshot you can save as PDF." %}

{% trans "Is the data secure?" %}

{% trans "Access requires UNICEF single sign-on and a registered account. Partner-level data, dashboards and reports are never public; the only public figures are the aggregate counts on this page." %}
