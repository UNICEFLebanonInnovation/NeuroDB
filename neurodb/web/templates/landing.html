{% trans "Questions we hear often" %}

{% trans "Who can use NeuroDB?" %}

{% trans "UNICEF Lebanon staff with a registered account. Viewers see all dashboards and reports, section editors can also comment on their section’s indicators, and administrators manage configuration. Selected resources can be opened to the public by the NeuroDB team." %}

{% trans "How do I get access?" %}

{% if SUPPORT_EMAIL %}{% blocktrans %}Write to {{ SUPPORT_EMAIL }} with your section and the role you need. Once registered, sign in with your UNICEF Microsoft account — no extra password.{% endblocktrans %}{% else %}{% trans "Ask the NeuroDB administrators in the Planning, Monitoring and Evaluation section. Once registered, sign in with your UNICEF Microsoft account — no extra password." %}{% endif %}

{% trans "Where does the data come from?" %}

{% trans "Programme documents, partner progress reports, funds, donors and assurance (monitoring visits, audits, action points, HACT) come from eTools through the eTools Datamart; monthly activity results from ActivityInfo; population estimates from the official planning figures loaded each year. NeuroDB never asks partners to report twice." %}

{% trans "How current is it?" %}

{% trans "eTools data synchronises every night, ActivityInfo imports run from the 1st to the 22nd of each month, and the daily review runs each morning after the syncs. The data health page shows when each source was last updated, and pages warn you when data is out of date." %}

{% trans "What does “on track” mean?" %}

{% trans "An indicator is on track when its achievement is within ten percentage points of the time that has passed: the share of the programme document’s period for eTools indicators, the share of the year for ActivityInfo ones. Well above is “ahead of schedule” (“over target” once it has passed its target), well below is “off track”, and indicators without a target are shown separately." %}

{% if AI_ASSISTANT_ENABLED %}
{% trans "What does the AI do, and what does it see?" %}

{% trans "Ask NeuroDB answers questions about the data and links to the pages its figures come from; the daily review’s checks are fixed rules, with a short written summary on top. Both only read data. They use the OpenAI API: a question, the recent turns of its conversation and the figures looked up to answer it leave UNICEF’s Azure environment for that purpose. Treat findings as prompts to look, never as verdicts." %}

{% endif %}
{% trans "Can I export the data?" %}

{% trans "Yes. Every table can be copied or downloaded as CSV, raw data is available in Excel, and dashboards have a printable snapshot you can save as PDF." %}

{% trans "Is the data secure?" %}

{% trans "Access requires UNICEF single sign-on and a registered account. Partner-level data, dashboards and reports are never public; the only public figures are the aggregate counts on this page." %}
